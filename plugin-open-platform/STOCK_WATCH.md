# 네이버 관심 주식 1.1.0

폰에서 네이버 종목 검색 → 결과의 관심 등록 → 안경에서 종목 선택 → 현재가·전일대비 금액·등락률·선차트 확인. 별도 APK·로그인·음성인식은 사용하지 않습니다.

## 최신 설치 파일
`dist/naver-stock-watch-1.1.0/`에 폰 MMPKG, 안경 GMP(버전 2), 동일 빌드 리뷰 파일 2개가 있습니다. 기존 `dist/stock-watch/`는 야후 구버전입니다.
Studio에서 최신 GMP·review.json·review-source.enc·MMPKG를 선택해 공식 설치 ZIP/QR을 생성해야 합니다. 임의 ZIP으로 묶어 설치하지 마세요. 실제 기기 설치는 아직 하지 않았습니다.

## 사용
1. 폰 검색창에 종목명 또는 코드(삼성전자, SK하이닉스, 005930)를 입력합니다. 400ms 후 네이버 실제 검색을 실행하며 검색 버튼·Enter도 지원합니다.
2. 종목명·코드·시장을 확인하고 **관심 등록**을 누르면 바로 저장합니다. 최대 20개, 중복 방지, 삭제, 순서 변경을 지원합니다. 코드 직접 등록은 보조 메뉴입니다. 검색은 내장 목록이 아닙니다.
3. 국내 6자리 코드의 코스피·코스닥·코넥스 종목을 지원합니다. 네이버 검색이 반환하는 국내 ETF 등이 포함될 수 있습니다. 해외 종목은 이번 버전의 지원 범위가 아닙니다.
4. 안경: 한 번 이동, 두 번 선택·실행, 길게 목록. 상세화면에서 기간 변경·새로고침·목록을 선택합니다. 당일·1개월·3개월·1년을 지원합니다.
5. 기존 .KS/.KQ 관심코드는 국내코드로 읽고 새 저장소에 저장합니다. 미국 등 해외코드는 제외하며 이전 저장소를 삭제하지 않습니다. 야후용 중계 설정은 자동 재사용하지 않습니다.

폰 플러그인이 실행 중이어야 안경 입력과 시세 조회가 처리됩니다. 종료·절전 상태의 독립 조회는 지원하지 않습니다.

## 실제 사용 데이터 주소
- 검색: https://ac.stock.naver.com/ac?q={검색어}&target=stock
- 기본시세: https://m.stock.naver.com/api/stock/{코드}/basic
- 당일 분차트: https://api.stock.naver.com/chart/domestic/item/{코드}?periodType=day
- 일별 종가: https://api.finance.naver.com/siseJson.naver?symbol={코드}&requestType=1&startTime=YYYYMMDD&endTime=YYYYMMDD&timeframe=day

첨부된 /api/stock/{코드}/price?pageSize=... 는 실제 응답이 일별 기록이므로 당일 분차트에 사용하지 않았습니다. 지수 조회는 이번 관심종목 기능 범위에 포함하지 않습니다. 위 주소는 웹 서비스 내부 주소이며 정식 외부 개발자 API의 안정성·영구 제공을 보장하지 않습니다. 자동 수집·이용·재배포 조건을 확인해야 합니다.

## CORS 및 선택형 중계 (APK 없음)
이 PC에서 검색·기본시세·당일차트·일별차트를 HTTP 200으로 수신·파싱했습니다. 인증 중계로도 실제 조회를 검증했습니다. 다만 확인한 응답에 브라우저 CORS 허용 헤더가 없어 일반 웹 fetch는 차단될 수 있습니다. MemoMind 실기 WebView는 미검증입니다. 직접 연결이 막히면 아래 중계를 연결해야 합니다. 플러그인에서 CORS 정책을 해제하지 않습니다.

Node 20 이상에서 저장소 루트 기준 `node integrations/stock-watch/server.mjs` 실행. 기본값은 실행한 PC의 127.0.0.1:18771입니다. 최초 생성되는 integrations/stock-watch/connection-key.txt는 공개하지 마세요.
USB 개발: `adb reverse tcp:18771 tcp:18771` 후 폰의 데이터 연결에 http://127.0.0.1:18771 및 위 키를 저장합니다. PC·USB·서버가 켜져 있어야 합니다. reverse를 자동 실행하지 않았습니다.
독립 사용: 본인이 운영하는 서버에 배치하고 HTTPS 역방향 프록시를 연결합니다. STOCK_TOKEN으로 강한 키를 설정하고 필요한 경우에만 STOCK_HOST를 지정합니다. 폰에는 HTTPS 기본 주소와 키를 저장합니다. 아직 배포한 서버는 없습니다.

서버는 고정 네이버 도메인의 허용된 경로만 전달하며 인증, 60초 캐시, 동시요청 제한, upstream 429 후 2분 대기를 적용합니다. 검색어·종목코드가 네이버 및 설정한 중계로 전달됩니다. 관심 목록과 중계 키는 폰 플러그인 비공개 저장소에 저장합니다.

## 표시 및 검증
기본시세의 closePrice·등락 금액·등락률·시각·지연값을 사용하며 하락 부호를 정규화합니다. 세션·갱신주기에 따라 타 서비스와 가격이 다를 수 있습니다. 당일 차트는 priceInfos만 쓰고 이전 거래일 lastPriceInfos와 섞지 않습니다. 일별 배열은 eval 없이 파싱합니다. null 가격은 제외하고 시간순 정렬합니다. 거래 순서 기준 균등 간격이며 수정주가 여부를 보장하지 않습니다. 새로고침에도 60초 캐시가 적용됩니다. 현재가만 성공하면 유지하고 차트 실패를 별도로 표시합니다.

자동 테스트 11개 통과. 실제 한글·코드 검색, 시세·차트 응답 및 인증 거부를 확인했습니다. Studio 최종 설치 ZIP 생성, 실제 안경 화면·버튼, 폰 WebView 직접 조회·절전 동작은 아직 미검증입니다.

## 1.2.1 업데이트 — HTTPS 자동 연결 및 페어 호환 수정
최신 폴더는 `dist/naver-stock-watch-1.2.1/`입니다. 이전 버전 안내보다 이 절차가 우선합니다.

HTTPS 서버를 Sites에 실제 배포했습니다: https://memo-naver-stock-relay.majorfacet1.chatgpt.site
사용자 승인으로 공개 조회 접근을 허용했습니다. 서버는 조회 전용이며 관심 목록·계좌정보를 저장하지 않습니다. 검색어·종목코드는 중계를 거쳐 네이버에 전달됩니다. 노출된 조회 주소의 요청 제한·캐시는 Worker 인스턴스 단위이며 영구적인 전역 사용량 제한은 아닙니다.

폰 1.2.1에는 서버 주소가 내장되어 있으므로 PC·USB·서버 주소·연결 키 입력이 필요하지 않습니다. 기존 로컬 중계 서버는 선택적인 개발용입니다. 검색 실패를 유발하던 네이버 직접 호출 경로를 기본 동작에서 제거했습니다. 실제 공개 URL에서 health·한글 검색·기본시세·당일차트·일별차트 HTTP 200 및 OPTIONS 204와 CORS *를 확인했습니다.

### '호환되지 않는 페어: Requires glass plugin ...' 해결
폰의 requiredPluginId가 특정 안경 패키지를 강제하던 문제를 제거하고 공식 문서 권장대로 표준 프로토콜 3개로 호환성을 확인합니다. 안경 식별자는 preferredPluginId로만 유지합니다. 배포 GMP 옆에 manifest.json을 함께 넣어 Studio가 프로토콜을 확인할 수 있게 했습니다.

1. Studio에서 예전 폰 패키지 대신 **NaverStockWatch-1.2.1.mmpkg**를 다시 가져와 선택합니다.
2. 같은 폴더의 **stock_watch_glass.gmp**를 가져옵니다. **manifest.json은 GMP 옆에 그대로 두세요.** 안경 표시 이름은 Naver Stock Watch Glass, 버전 2입니다.
3. 여전히 이전 이름·호환 오류가 보이면 Import workspace로 저장소 루트를 가져오고 새로고침 후 해당 폰·안경 조합을 선택합니다.
4. 이 조합으로 Studio 공식 설치 ZIP/QR을 생성하고 MemoMind 앱에서 갱신합니다. 파일을 임의로 묶은 ZIP은 설치 패키지가 아닙니다.

빌드 페어 선언·프로토콜 3개·GMP 리뷰 해시를 확인했고 데이터 테스트 11개, Worker 테스트 4개가 통과했습니다. 실제 안경 화면·버튼 및 MemoMind 앱 WebView에서의 동작은 여전히 기기 확인이 필요합니다. 이전에 표시된 'Requires glass plugin' 문구가 그대로면 구버전 폰 패키지가 선택된 것입니다.

## 1.3.0 업데이트 — 목록 시세 자동 갱신
최신 폴더: `dist/naver-stock-watch-1.3.0/`.
폰 패키지는 NaverStockWatch-1.3.0.mmpkg, 안경은 기존 Naver Stock Watch Glass 버전 2와 호환됩니다. 폴더에 안경 GMP·리뷰 파일·manifest.json도 포함했습니다. Studio에서 폰 패키지를 새 버전으로 다시 선택해 공식 설치 패키지를 생성하세요.

안경 목록: 왼쪽에 종목명·코드, 오른쪽에 현재가·전일대비 금액·등락률을 두 줄로 표시합니다. 선택 배경에서도 검정 글씨로 구분합니다. 페이지당 최대 5개 종목을 15초마다 순차 갱신하며 화면 이동·절전·종료 시 이전 요청을 취소합니다. 상세 화면의 현재가·등락 정보도 같은 주기로 갱신하지만 차트는 기존 조회 방식입니다. 폰 관심 목록에도 수신한 시세를 표시합니다. 보이지 않는 페이지는 해당 페이지로 이동할 때 조회합니다.

네이버 기준 시각을 표시하며 조회 실패 시 기존 값을 유지하되 이전값·갱신 실패로 표시합니다. 45초 넘게 새로 받지 못한 값도 이전값으로 구분합니다. 실시간 체결 스트리밍이 아닌 15초 주기 조회이고 네이버 공급 지연·장 마감 시 가격이 그대로일 수 있습니다. 중계의 기본시세 캐시는 10초, 검색·차트 캐시는 60초입니다.

기존 공개 HTTPS 서버를 1.3.0으로 갱신 배포했습니다. 데이터·갱신 테스트 16개, Worker 테스트 4개, 패키지 프로토콜 및 GMP 리뷰 해시 검증을 통과했습니다. 실제 안경에서 이번 목록 배치와 타이밍 검증은 아직 필요합니다.

## 1.4.0 업데이트 — 보유 주식 및 총 자산 현황
최신 폴더는 `dist/naver-stock-watch-1.4.0/`입니다. 폰 NaverStockWatch-1.4.0.mmpkg와 기존 안경 버전 2를 사용합니다. Studio에서 새 폰 패키지를 선택해 공식 설치 ZIP/QR로 갱신하세요.

폰의 **보유 주식 · 평균단가**에서 등록된 종목을 고르고 보유 수량·평균 매입단가(원)를 저장합니다. 수량은 소수 6자리, 평균단가는 소수 2자리까지 지원합니다. 수량 0을 저장하면 해제합니다. 보유 정보가 있는 관심 종목은 수량을 0으로 해제한 후 삭제할 수 있습니다. 보유 수량·평균단가는 `stockHoldings.naver.v1`에만 저장하며 서버에 전송하지 않습니다. 주기적 시세 갱신이 입력 중인 수량·단가를 덮어쓰지 않습니다.

평가액 = 현재가 × 수량, 매입금액 = 평균단가 × 수량, 평가손익 = 평가액 − 매입금액, 수익률 = 평가손익 ÷ 매입금액 × 100. 내부 금액은 정수 고정소수점으로 계산하고 종목별 0.01원 단위로 반올림한 뒤 합산합니다. 현금·예수금·다른 자산·실현손익·세금·수수료는 포함하지 않습니다. 증권사 잔고를 자동 연동하는 기능이 아니므로 매매 후 수량과 평균단가는 직접 수정해야 합니다.

안경 목록·상세 화면 하단에 **총 자산 (보유 주식)**, 매입금액, 평가손익·수익률을 표시합니다. 보유 정보가 있으면 목록은 페이지당 4개로 줄여 합계 공간을 확보하고 상세 차트 높이도 조정합니다. 화면에 보이지 않는 보유 종목을 포함해 모두 조회합니다. 일부 가격이 누락되면 부분 금액을 전체 합계처럼 표시하지 않고 시세 확인 수/전체 수와 계산 대기를 표시합니다. 조회 실패·45초 넘게 수신하지 못한 값은 이전값으로 표시합니다.

보이는 관심 종목과 전체 보유 종목을 합쳐 중복 제거 후 조회합니다. 조회 대상 10개 이하는 15초, 11개 이상은 30초 주기입니다. 거래마다 갱신되는 스트리밍 시세가 아닙니다. 기존 HTTPS 서버는 그대로 사용하며 별도 APK·서버 변경은 필요하지 않습니다.

계산·보유정보 검증·누락가격·이전값·갱신 테스트 총 23개 및 빌드 페어 검증을 통과했습니다. 실제 안경에서 이번 자산 영역의 시인성과 레이아웃은 추가 확인이 필요합니다.

## 1.4.1 업데이트 — 종목별 보유 수량·매입금액 표시
최신 폴더: `dist/naver-stock-watch-1.4.1/`. 폰 패키지를 1.4.1로 교체하며 안경 플러그인은 버전 2 그대로 사용합니다.
보유 정보가 있으면 안경 목록을 페이지당 3종목으로 구성합니다. 각 종목은 첫 줄 종목명·현재가, 둘째 줄 종목코드·등락 금액/등락률, 셋째 줄 보유 주식수·총 매입금액을 표시합니다. 매입금액은 평균 매입단가×수량이며 평균단가 자체와 다릅니다. 좌우 영역을 분리하고 종목 행과 총 자산 하단 사이에 여백을 확보했습니다. 보유 미등록 종목은 숫자 0 대신 미등록/—로 구분합니다. 소수 수량은 6자리까지 보입니다. 상세 화면에도 등락 정보 다음에 보유 수량과 매입금액을 표시하고 기준 시각·차트 영역을 아래로 조정했습니다.
총 자산 계산과 저장 정보는 유지하며, 이번 변경은 폰 플러그인이 그려서 전송하는 화면 변경입니다. 자동 테스트 23개 및 빌드를 통과했습니다. 실제 안경 시인성과 간격은 미검증입니다.

안경 목록을 왼쪽부터 **종목 → 시세·등락률 → 보유주식 → 현재 자산**의 네 열로 구성했습니다. 열별 제목과 고정 영역을 두고 사이에 16px 이상의 간격을 확보했습니다. 종목명/코드, 현재가/등락률은 두 줄이며 수량과 현재 평가금액은 각각 별도 열입니다. 마지막 열은 매입금액이 아니라 **현재가×보유수량**의 평가액입니다. 미보유는 —, 시세 미수신은 조회 중, 오래된 시세는 이전 시세로 구분합니다. 상세 화면의 보유수량 오른쪽도 현재 자산으로 바꾸었습니다. 보유 정보가 있으면 3종목씩 표시하고 하단 총 자산은 유지합니다. 문법 확인·패키지 빌드를 통과했으며 실제 안경 시인성은 미검증입니다.
