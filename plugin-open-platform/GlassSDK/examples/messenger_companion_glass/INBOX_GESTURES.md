# 수신 메시지 목록과 머리 동작 선택 — Android 1.3.0 / Glass 3

## 사용

| 동작 | 기능 |
|---|---|
| 머리 왼쪽 / 오른쪽 | 이전 / 다음 메시지 |
| 고개 위로 / 아래로 | 긴 본문 이전 / 다음 페이지 |
| 끄덕임 | 현재 메시지를 답장 대상으로 선택 |
| 고개 좌우 흔들기 | 답장 선택 취소 후 목록으로 복귀 (녹음·인식 중에는 무시) |
| 안경 한 번 누르기 | 현재 메시지 답장 선택 |
| 두 번 누르기 | 안경 마이크 시작 / 완료 |
| 길게 누르기 | 인식 결과 최종 전송 |
| Back | 음성 입력 또는 답장 취소 |

전송은 머리 동작으로 자동 실행하지 않습니다. 녹음·인식 중에는 머리 동작을 무시하며, 답장을 선택한 동안 메시지·본문 탐색을 잠급니다. 취소한 뒤 다른 메시지를 선택하세요. 인식 결과를 확인하고 길게 눌러야 전송합니다.

완료 후 화면이 꺼진 상태에서는 끄덕임이나 버튼으로 현재 메시지를 다시 열 수 있습니다. 좌우 머리 동작으로 다른 메시지를 열 수도 있습니다. 화면 전원을 끄더라도 플러그인과 IMU 이벤트가 계속 실행되는지는 기기 펌웨어에서 확인해야 합니다.

휴대폰에도 메시지 목록·이전/다음·본문 페이지 버튼을 추가했습니다. 목록에서 발신자와 내용을 보고 직접 선택할 수 있습니다.

휴대폰의 ‘메시지 3건·긴 본문 탐색 테스트’를 누르면 카카오톡·Telegram·뮤즈AI 모의 메시지 3건을 추가합니다. 실제 발송 없이 머리 탐색·긴 본문·선택·음성 답장·화면 꺼짐을 시험할 수 있습니다.

## 수신 범위

- 카카오톡·Telegram·설정된 뮤즈AI가 Android 알림으로 제공한 메시지를 처리합니다.
- 서비스 시작 시 현재 Android 알림창에 남은 지원 메신저 알림을 모두 읽습니다.
- MessagingStyle에 여러 메시지가 들어 있으면 각각 목록에 추가하고 알림 키·발화 시각·발신자·본문으로 중복을 줄입니다. null sender로 표시된 자신의 발신 메시지는 제외합니다.
- 메시지마다 ‘메시지 3/12 · 본문 1/4’처럼 위치를 표시합니다. 한 메시지 본문은 최대 12,000자이며 UTF-8 안전한 페이지로 나눕니다.
- 서비스 실행 중 최신 300건을 메모리에 보관합니다. 한도를 넘으면 현재 보고 있는 메시지를 보호하면서 오래된 항목을 제외하고 상태 기록에 표시합니다.
- 서비스 중지·앱 종료 후 이력은 남기지 않습니다. 메신저 내부 전체 대화, 알림에 없던 과거 메시지, 앱이 숨긴 내용은 읽을 수 없습니다. 이 기능은 ‘모든 채팅 기록’ 동기화가 아닙니다.
- 새 메시지가 와도 음성 입력·답장 작성 중인 대상과 초안을 바꾸지 않습니다. 새 메시지는 목록에 추가됩니다.

## 답장 대상 보호

메시지 내용과 Android 답장 액션을 분리했습니다. 과거 알림이 지워져도 내용은 실행 중 이력에서 볼 수 있지만 답장 액션은 즉시 제거합니다. 같은 대화 알림에 여러 메시지가 있었으면 답장은 선택한 메시지가 속한 대화의 현재 유효한 RemoteInput으로 보냅니다. 메신저의 특정 원문을 인용하는 답장 기능은 제공하지 않습니다.

새 메시지가 도착해도 현재 답장 대상을 바꾸지 않고, 안경 명령은 현재 화면 작업 ID와 일치해야 합니다. 메시지·본문을 이동할 때 ID를 갱신하여 이전 화면의 지연 명령을 무시합니다. 원래 Android 알림이 존재하고 현재 답장 액션이 유효할 때만 전송합니다.

Android 알림 ID를 다른 대화에 재사용하는 경우를 막기 위해 shortcut ID를 우선 사용하고, 없으면 대화 제목으로 구분합니다. 전송 직전에도 시스템의 현재 알림과 대화 식별자를 다시 대조합니다. 메신저가 같은 ID와 동일 제목을 서로 다른 대화에 사용하면서 식별 정보를 주지 않으면 앱에서 완벽하게 구분할 수는 없습니다.

## 양쪽 업데이트 필요

1. 휴대폰: `MemoMessengerCompanion-1.3.0-debug.apk`를 덮어 설치합니다.
2. Studio: SDK 루트 `run-messenger-companion.cmd`를 실행합니다.
3. **Import package** → `dist/MemoMessengerCompanion-Glass-Studio.zip`을 선택합니다.
4. **Memo Messenger Companion Glass (APK)**를 선택하고 Phone은 비활성화합니다.
5. Studio QR로 Glass **빌드 3**을 설치·실행합니다.
6. 보조 앱에서 안경을 다시 연결합니다.

새 Android 앱의 표시 메시지는 버전 4(상태 플래그 포함)를 사용합니다. 기존 Glass 빌드 2는 이 표시 형식을 처리하지 못하므로 APK만 업데이트하면 안 됩니다. 버튼/머리 명령은 기존 버전 2 패킷에 이전·다음·새로고침·본문 이전·다음 명령(5~9)을 추가했습니다. 화면 꺼짐 제어는 버전 3 그대로입니다.

## 검증

메시지 중복·정렬·탐색·현재 대상 유지·전송 상태 유지·한도 보호·전체 본문 복원·상태 패킷 크기 테스트를 추가했습니다. Android와 Glass 빌드 및 패키지 검증 결과는 Android 검증 보고서를 참고하세요. 실제 안경의 IMU 감도·좌우 방향·펌웨어 지원과 메신저 발송은 실기기 확인이 필요합니다. 빌드 성공은 머리 동작의 실기기 동작 보장을 의미하지 않습니다.

최종 단위 테스트는 33개 통과했고 Android Lint 오류는 0건입니다. 현재 arm64 폰 전용 빌드라 ChromeOS x86_64 미지원 경고는 남아 있습니다.
