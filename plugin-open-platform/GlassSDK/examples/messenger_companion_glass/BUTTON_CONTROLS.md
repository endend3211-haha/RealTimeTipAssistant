# 버튼 중심 메시지 읽기·답장 — Android 1.4.0 / Glass 4

## 조작

| 상태 | 입력 | 동작 |
|---|---|---|
| 메시지 목록 | 머리 좌우 | 이전·다음 항목에 포커스 이동 |
| 메시지 목록 | 버튼 한 번 | 포커스된 메시지를 열기 |
| 메시지 읽기 | 고개 위아래 | 긴 본문 이전·다음 페이지 |
| 메시지 읽기 | 버튼 한 번 | 이전 메시지 목록으로 복귀, 같은 항목에 포커스 유지 |
| 메시지 읽기 | 버튼 두 번 | 현재 메시지에 답장할 안경 음성 입력 시작 |
| 음성 입력 중 | 버튼 두 번 | 입력 종료 후 한국어 인식 |
| 인식 결과 확인 | 버튼 길게 | 답장 요청 전송 |
| 읽기·음성·결과 확인 | 버튼 한 번 또는 Back | 음성·초안 취소 후 목록으로 복귀 |

끄덕임으로 메시지를 여는 동작은 제거했습니다. 머리 좌우는 목록에서만, 위아래는 메시지를 연 상태에서만 동작합니다. 녹음·인식 중에는 머리 동작을 무시합니다. 음성 답장을 시작한 후에는 본문 넘김도 잠그며, 한번 눌러 목록으로 나간 후 다시 열어 읽을 수 있습니다.

읽기 전용·만료된 메시지도 한번 눌러 열고 긴 본문을 읽을 수 있습니다. 다만 해당 메시지의 음성 답장과 전송은 차단합니다. 메시지를 열기만 한 상태에서 길게 누르면 전송하지 않습니다. 음성 인식 결과를 확인한 뒤 길게 눌러야 전송합니다.

메시지를 읽는 중 새 알림이 와도 현재 본문과 답장 대상은 유지합니다. 전송 요청 성공 후 완료 문구를 표시하고 1.5초 뒤 화면을 끄는 동작은 유지합니다. 화면이 꺼진 뒤 한 번 누르면 읽던 항목이 선택된 목록으로 돌아오도록 요청합니다.

화면이 꺼진 동안에는 머리 동작을 무시합니다. 새 메시지가 오거나 버튼을 누르면 다시 화면을 엽니다.

## 업데이트

휴대폰은 `MemoMessengerCompanion-1.4.0-debug.apk`, 안경은 **Memo Messenger Companion Glass (APK) 빌드 4**로 함께 업데이트해야 합니다. 표시 패킷 버전 5에 읽기 상태 플래그를 추가했으므로 이전 Glass 빌드와 혼용하면 안 됩니다.

Studio에서 SDK `dist/MemoMessengerCompanion-Glass-Studio.zip`을 다시 Import package하고 새 QR로 안경 플러그인을 업데이트하세요. Phone 웹 플러그인은 비활성화합니다.

전체 메시지 목록·오프라인 Whisper·대화 식별자 보호는 1.3.0과 동일합니다. 최신 사용 기준은 이 문서이며, 1.3.0 안내의 끄덕임 선택 방법은 더 이상 적용하지 않습니다.

## 검증

단위 테스트와 Android/Glass 빌드에 더해, 연결된 Android 기기에서 외부 메시지 발송 없이 모의 메시지로 실제 서비스의 목록→열기→페이지→목록 복귀, 선택 대상 유지, 오래된 전송 명령 거부, 읽기 전용 차단 처리를 검사합니다. 실제 안경 버튼·IMU와 음성 녹음·메신저 발송을 통한 전체 흐름은 별도 실기기 검증 대상입니다.

Samsung SM-S936N에 Android 1.4.0(versionCode 5)을 설치했습니다. 위 기기 모의 흐름 검사는 통과했고 단위 테스트는 34개 통과했습니다. Android Lint 오류 0건이며 arm64 폰 전용 빌드의 ChromeOS x86_64 미지원 경고는 유지됩니다.
