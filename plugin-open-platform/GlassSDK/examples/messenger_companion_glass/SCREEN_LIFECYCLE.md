# 알림 → 음성 답장 → 화면 자동 꺼짐 (Android 1.1.0 / Glass 빌드 2)

## 변경 동작

1. 새 메신저 알림 수신 시 안경 화면 전원을 켜고 발신자·본문을 표시합니다.
2. 안경 한 번 누르기로 답장 선택, 두 번으로 안경 마이크 시작, 다시 두 번으로 음성 인식을 완료합니다.
3. 인식된 답장을 확인하고 길게 눌러 전송합니다.
4. Android가 원래 알림의 PendingIntent 답장 요청을 성공적으로 전달하면 완료 문구를 표시합니다.
5. 완료 문구 전달 ACK 후 1.5초 뒤 SDK `display_control.screen_turn_on(false)`로 화면 전원 끄기를 요청합니다.
6. 이후 새 메시지가 도착하면 화면을 다시 켭니다.

답장 요청 전달은 상대방의 수신 확인이 아닙니다. 메신저가 제공하는 알림 액션 실행 성공을 기준으로 화면을 끕니다. 테스트 알림의 모의 전송 완료 후에도 같은 화면 꺼짐 흐름을 사용합니다.

## 업데이트 방법

휴대폰의 `MemoMessengerCompanion-1.1.0-debug.apk`와 안경의 새 Glass 빌드 2를 모두 업데이트해야 합니다. 기존 앱 설정을 유지하는 덮어쓰기가 가능합니다.

1. 보조 앱 연결 서비스를 중지합니다.
2. 휴대폰에 새 APK를 덮어 설치합니다.
3. SDK 루트의 `run-messenger-companion.cmd`를 실행합니다.
4. Studio **Import package**에서 SDK `dist/MemoMessengerCompanion-Glass-Studio.zip`을 선택합니다.
5. **Memo Messenger Companion Glass (APK)**가 선택되고 Phone이 비활성화되어 있는지 확인합니다.
6. Studio QR로 안경 플러그인을 업데이트·실행합니다. ID는 기존과 동일하고 빌드 버전은 1에서 2로 올렸습니다.
7. 보조 앱에서 안경을 다시 연결합니다.

## 화면 꺼짐 보호 조건

- 메신저 답장 요청 전송 실패 또는 완료 문구 전달 실패 시 화면 끄기를 예약하지 않습니다.
- 대기 중 새 알림이 오면 이전 답장의 화면 끄기 예약을 무효화합니다.
- 안경도 현재 표시 중인 알림 ID와 일치하는 화면 끄기 명령만 처리합니다.
- 전송 후 메신저가 원래 알림을 제거해도 화면 끄기 예약을 유지하고 만료 문구로 화면을 다시 켜지 않습니다.
- 취소·연결 종료 시 화면 끄기 예약과 오래된 응답을 무효화합니다.
- 안경이 화면 끄기 요청 결과를 별도 응답합니다. 3초 내 응답이 없으면 휴대폰에 Glass 업데이트 확인 안내를 표시합니다.
- 화면 전원 API가 없는 Host는 새 플러그인의 실행 요구조건을 충족하지 않습니다. 검은 화면 그리기로 성공을 가장하지 않습니다.

## 통신

기존 채널 20051과 버전 2 텍스트·버튼 명령을 유지합니다. 화면 제어용 메시지만 버전 3을 추가했습니다.

- Android → Glass: `version:u8=3, opcode:u8=0, notification_id:64 bytes` (66 bytes)
- Glass → Android: `version:u8=3, opcode:u8=0, result:u8, notification_id:64 bytes` (67 bytes)
- `result=0`은 화면 전원 끄기 요청을 Host가 수락했다는 뜻이며 실제 패널 상태 실측은 아닙니다.

## 검증 범위

Android APK 빌드·프로토콜 및 화면 수명 테스트 15개·Lint와 Glass RISC-V 빌드·패키지 해시 검증을 통과했습니다. 연결된 Samsung SM-S936N에 보조 앱 1.1.0(versionCode 2)을 덮어 설치하고 실행했습니다. 실제 안경 패널의 전원 전환과 메신저 송수신은 아직 확인하지 못했습니다. 안경 플러그인은 Studio QR로 별도 업데이트해야 합니다.
