# GLOW OS Plus

MemoMind One용 날씨·뉴스·주식·테트리스·세계시계·계산기·메모 플러그인입니다.

## 설치
release/GLOW-OS-Plus-1.1.8.zip의 폰 1.1.8과 글라스 버전 5를 MemoMind Studio에서 페어로 패키징합니다. ZIP 내 안내를 참고하세요. 별도 APK는 필요하지 않습니다.

## 소스 빌드
이 저장소는 앱 소스이며 전체 SDK가 아닙니다. 제조사의 matching plugin-open-platform SDK에 PhoneSDK/examples/glow-market 및 GlassSDK/examples/glow_os_plus_glass를 복사해 공식 빌드 도구로 빌드합니다. 포함된 Web SDK·빌드 산출물과 공식 SDK 버전 호환성을 확인하세요.

## 제한
뉴스·주식은 기존 공개 중계서버를 사용하며 서버 운영권·소스는 이 저장소에 포함하지 않습니다. 개인 메모·관심종목·보유 정보는 포함하지 않았습니다. 음성 메모는 현재 MemoMind 웹뷰에서 지원되지 않습니다. 게임 종료 멈춤은 복구 코드를 보강했으나 실기기 해결은 미확정입니다. 배터리 실기기 수신·TTS·위치 권한은 대상 기기 확인이 필요합니다. 계정 소유권·공유 제한은 MemoMind 정책을 따릅니다.

플랫폼 기반 코드의 라이선스는 LICENSE를 확인하세요.
