# GLOW OS Plus 1.1.24

MemoMind용 폰·글라스 플러그인 앱 소스입니다. 폰 버전 1.1.24, 글라스 버전 11 소스를 포함합니다.

제조사 matching plugin-open-platform SDK의 동일 경로에 복사하여 공식 도구로 빌드·Studio 패키징해야 합니다. SDK 전체와 중계서버, 별도 Android 앱은 포함하지 않습니다. 원본 플랫폼 라이선스는 LICENSE를 확인하세요.

이 소스 버전의 실기기 검증 상태와 추가 네이티브 앱·중계 의존성은 각 기능 코드 및 설정을 확인하세요. 이전 1.1.8 설치 ZIP은 이 버전의 설치 파일이 아니므로 포함하지 않았습니다.

상용 게임 ROM 파일은 제외했습니다. 해당 게임은 합법적으로 사용할 수 있는 ROM을 별도로 준비해야 합니다. 메신저 등 외부 앱 연동은 별도 의존성을 확인하세요.
