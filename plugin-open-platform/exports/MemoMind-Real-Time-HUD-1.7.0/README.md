# MemoMind Real-Time HUD 1.7.0

MemoMind 폰·글라스 HUD 플러그인 소스 및 기존 설치 패키지입니다. 개인 데이터·인증키·중계서버 소유권은 포함하지 않습니다.

release의 폰 MMPKG 버전은 1.7.0입니다. Studio ZIP은 기존 파일을 변경 없이 보존했으며 이전 폰 버전 파일도 함께 포함되어 있으므로 반드시 1.7.0을 선택하세요. MemoMind 공식 Studio/앱의 설치·소유권·공유 정책에 따라 설치합니다.

소스 빌드는 matching plugin-open-platform SDK의 동일 위치에 폴더를 복사하여 공식 도구로 빌드합니다. 전체 SDK는 포함하지 않습니다. SDK 기반 코드의 조건은 LICENSE를 확인하세요. 이번 업로드는 기존 1.7.0 보관용으로 실제 폰·안경 동작을 새로 검증하지 않았습니다.
