안경에서 시작하기

버튼을 한 번 누르거나 짧게 고개를 끄덕이세요.

스마트폰 준비

  1. Google/Gemini를 기본 디지털 어시스턴트로 설정하세요.
  2. 수신기 앱에서 알림 권한을 허용하고 수신을 시작하세요.
  3. 안경의 블루투스 통화 오디오 연결을 확인하세요.
  4. 휴대폰 잠금을 해제하고 이 플러그인을 실행하세요.

수신기가 백그라운드에 있으면 “Gemini 열기” 알림을 눌러주세요. 분할 화면 등으로 수신기가 보이는 동안에는 직접 실행을 요청합니다. Gemini Live는 앱에서 Live 버튼을 눌러야 할 수 있습니다.

이 버전은 외부 앱 스킴으로 이동하지 않습니다. 로컬 HTTP도 MemoMind 앱의 네트워크 정책으로 차단될 수 있으며 network 권한만으로 허용을 보장할 수 없습니다.

API 키·클라우드·외부 자동화 앱은 사용하지 않습니다. 별도 수신기 APK는 필요합니다.
