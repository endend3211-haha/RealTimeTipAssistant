안경 화면

아직 전송하지 않았습니다.

한글 제목과 표지는 휴대폰에서 그립니다. 안경에는 회색조 화면만 보냅니다.

예제는 직접 만든 테스트 그림이며 실제 웹툰 본문이 아닙니다.

Android 전체 화면 읽기 연동이 필요합니다.

이 API는 작품 정보만 제공합니다. 실제 본문은 Android 모듈이 공식 웹툰 사이트에서 표시합니다.
