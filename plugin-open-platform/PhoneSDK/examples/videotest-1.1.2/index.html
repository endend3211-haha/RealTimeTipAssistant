영상

영상 스타일

선명은 픽셀을 그대로 표시합니다. 부드럽게는 옅은 주사선을, 복고풍 TV는 주사선과 로딩 중 잡음 화면을 표시합니다.

CRT 효과

영상에 옅은 주사선을 겹쳐 픽셀 경계가 덜 도드라집니다.

경계 부드럽게

작은 영상을 확대할 때 픽셀 경계를 부드럽게 처리합니다.

밝은 영역 눈부심 완화

하늘, 흰 벽, 밝게 비친 얼굴의 눈부심을 줄입니다.

화면 채우기

화면 비율을 유지하면서 안경에 최대 크기로 표시합니다.

소리 및 로딩

소리

로딩 중 TV 잡음 화면

잡음 효과음

영상 로딩 중 안경에 잡음 화면이 표시됩니다. 소리 출력이 휴대폰일 때만 효과음이 재생됩니다.

채널 전환 중 광고

채널 전환이 지연되면 안경에 가상의 광고와 날씨, 시각, 편성 정보를 표시하고 휴대폰이 읽습니다. 영상이 나오면 멈춥니다.

재생 및 채널

이어서 재생

영상이 끝나면 목록의 다음 항목을 재생합니다. 안경 한 번은 재생·일시 정지, 두 번은 다음, 세 번은 이전, 길게 누르면 자막을 전환합니다.

한 번 누르면 다음 채널

실시간 방송에서 한 번은 다음, 두 번은 이전, 세 번은 직전에 본 채널, 길게 누르면 자막입니다. 끄면 영화와 같은 조작을 사용합니다.

이전·다음 채널 미리 준비

빠른 채널 전환

재생 중 이전·다음 채널을 미리 불러옵니다. 배터리와 데이터를 더 사용하며, IPTV는 두 번째 로그인이 있을 때만 사용합니다.

방송 편성표

실시간 탭에 NAS와 IPTV, Pluto TV, Tubi의 채널과 현재 방송을 분류해 표시합니다. 끄면 휴대폰의 기본 채널 목록만 표시합니다.

IPTV 채널

실시간 탭에 IPTV 구독 채널을 표시합니다. 동시에 한 스트림만 사용할 수 있으면 다른 IPTV 앱을 먼저 닫으세요. 로그인 정보는 엔진에 보관됩니다.

무료 채널 우선

즐겨찾기에 같은 방송의 무료 채널이 있으면 무료 스트림을 우선 재생합니다. IPTV 채널도 끄면 휴대폰에서 IPTV를 사용하지 않습니다.

휴대폰 소리 재생기

휴대폰 엔진을 사용할 때 Media Link로 소리를 재생해 MM Video의 메모리 사용량을 줄입니다. Media Link 0.8.0 이상이 필요합니다.

숨긴 채널

숨긴 채널이 없습니다. 채널을 숨기려면 실시간 탭에서 편집을 누르고 채널 옆의 숨기기를 선택하세요.

YouTube 채널

YouTube 탭에 즐겨찾는 채널을 표시합니다. 링크나 @이름으로 추가하고, 길게 눌러 삭제합니다. 끄면 링크 입력란만 표시합니다.

표지 이미지

둘러보기 항목에 채널 로고와 영상 표지를 표시합니다. 이미지가 없으면 머리글자가 표시됩니다.

즐겨찾기를 길게 눌러 삭제

현재 재생 표시줄

재생 중 상단에 정지 및 다른 콘텐츠 선택 버튼을 표시합니다.

커버 화면 터치패드

휴대폰을 접으면 커버 화면에서 터치패드를 자동으로 엽니다.

화면 보호기

켜면 대기 중 MM TV 배지가 움직입니다. 끄면 안경에 READY가 표시됩니다.

영상 세부 조정

영상 크기

작을수록 빠르고 클수록 선명합니다.

표현 방식

일반은 16단계 회색, 디더링은 점으로 계조를 표현합니다. 만화는 4단계와 윤곽선, 자동은 움직일 때 만화, 정지할 때 전체 계조입니다.

밝은 장면

강하게는 밝기와 섬광을 더 크게 완화합니다. 약하게는 보정 강도가 낮습니다.

어두운 장면

어두운 회색을 밝게 보정합니다. 검은색은 유지됩니다.

미세 노이즈 필터

미세한 회색 변화의 전송을 줄여 화면을 빠르게 표시합니다.

움직임이 많은 장면

속도는 작은 변화를 나중에 전송합니다. 세부 묘사는 모든 변화를 전송합니다.

동시 전송 프레임

2는 수신 완료 전에 다음 프레임을 보냅니다. 안경 화면이 멈추면 1로 바꾸세요.

장면 전환

장면이 전환되면 이전 화면을 지우도록 전체 프레임을 보냅니다.

PC 연동

PC 사용

기본적으로 휴대폰에서 실행합니다. 켜면 NAS, PC 스피커, PC 자막, PC 엔진을 사용할 수 있습니다.

엔진

IPTV에 PC 사용 허용

끄면 엔진을 PC로 직접 지정한 경우를 제외하고 휴대폰에서만 IPTV를 재생합니다. 켜면 휴대폰 재생 실패 시 PC로 시도합니다.

PC에서 자막 생성

휴대폰 재생 중 PC가 AI 자막을 생성합니다. IPTV와 PC 응답이 없을 때는 휴대폰을 사용합니다.

테스트 영상
