# Glow 뉴스 · 주식 · 폰 테트리스 1.0.5

메뉴 순서: 날씨 → 뉴스 → 주식 → 게임 → 세계 시계 → 계산기 → 메모.
이번 버전은 테트리스 실행 엔진을 폰 플러그인으로 변경했습니다. 네이티브 게임 실행 명령은 사용하지 않습니다. 게임 화면을 표준 원자적 LZ4 프레임으로 안경에 표시하고 버튼·고개 입력을 받아 폰에서 게임 상태를 갱신합니다. 별도 APK·API·게임 서버는 필요하지 않습니다. 원본 Glow 및 프로젝트 테트리스 파일은 수정하지 않았습니다.

## 설치
01_Phone/GlowMarket-Phone-1.0.5.mmpkg와 02_Glass/glow_market_glass.gmp(버전 3)를 Studio에서 페어로 선택해 패키징·설치하세요. manifest 및 review 파일을 함께 유지하세요. 이번에는 폰·글라스를 함께 교체하는 것을 권장합니다. ZIP은 전달용이며 Studio가 만드는 공식 설치 패키지를 대신하지 않습니다. 계정 소유권·공유 정책은 유지됩니다.

## 게임 실행
홈 → 게임 → 테트리스에서 버튼 한 번. 폰의 테트리스 실행 버튼으로도 열 수 있습니다.
- 고개 좌우 / 폰 좌우 버튼: 이동
- 안경 버튼 한 번 / 폰 회전 버튼: 회전
- 안경 버튼 두 번 / 폰 바로 내리기 버튼: 즉시 낙하
- 안경 버튼 길게: Glow 홈
- 게임 오버 후 버튼: 다시 시작
- 폰 일시정지 버튼: 일시정지/재개

앱이 백그라운드로 가거나 게임 화면을 벗어나면 자동 낙하·게임 프레임 전송이 멈춥니다. 앱 실행 중 게임 화면으로 돌아오면 이어서 진행합니다. 앱 종료 후 게임 상태는 유지하지 않습니다. Bluetooth 전송 품질에 따라 화면 지연이 생길 수 있으며 실제 안경 조작감은 별도 시험이 필요합니다.

## 별도 테트리스 플러그인
MemoTetris-Plugins-0.1.0.zip은 테트리스만 실행하는 별도 ID com.mcnex.tetris.phone 패키지입니다. Glow와 같은 표준 글라스 브리지와 페어링합니다. 단독판의 길게 누르기는 일시정지/재개이며 폰 상단 버튼도 동일합니다. Glow 내부 테트리스와 동일한 폰 게임 엔진을 사용합니다.

## 유지 기능
뉴스·주식은 기존 중계를 이용합니다. 현재 위치 날씨는 위치 권한이 필요하며 5분 간격 조회입니다. 모든 Glow 화면에서 길게 눌러 홈으로 복귀합니다. 관심종목·보유 정보는 새 플러그인 저장 공간을 사용합니다.

## 검증
게임 엔진의 블록 충돌·회전·줄 삭제·점수·게임 오버/재시작 4개 시험을 통과했습니다. 실제 Web SDK + 모의 호스트 브라우저에서 Glow 게임 실행·즉시 낙하·홈 복귀와 단독판의 자동 낙하·조작·점수·일시정지 시 프레임 중단을 확인했습니다. 뉴스·주식·위치·화면 전체 갱신 회귀 시험도 통과했습니다. 폰 패키지 검증 및 표준 글라스 네이티브 빌드를 통과했습니다. 실제 MemoMind 앱·안경에서의 설치·전송 속도·고개 조작은 아직 확인하지 않았습니다.
