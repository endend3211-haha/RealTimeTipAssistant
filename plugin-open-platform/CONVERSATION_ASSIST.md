# Memo 대화 도우미 0.1.0 — 단어 설명 프로토타입

## 현재 구성

안경 마이크 → 공식 MemoMind 앱/폰 플러그인 → 휴대폰 내부 127.0.0.1:18772 → 독립 APK의 Opus 디코더와 Whisper → 한국어 자막. 단어를 고르면 로컬 사전을 우선 사용하고, 사전에 없는 단어만 Gemma 4 E2B로 설명합니다. 외부 음성인식/AI API, 인터넷 중계 서버, 직접 블루투스 연결은 사용하지 않습니다. 상·중·하 선택 기능은 없습니다.

**듣기와 설명을 독립 처리합니다.** 설명을 요청해도 듣기를 의도적으로 멈추지 않습니다. 다만 백그라운드 정책, 처리 지연, 버퍼 초과 또는 연결 끊김으로 중단될 수 있습니다.

## 설치 파일

- MemoConversationAssist-0.1.0.apk: Android 12 이상 ARM64 개발 서명 앱. Whisper small Q5_1 한국어 인식 모델 포함, 약 213MB.
- MemoConversationAssist-0.1.0.mmpkg: MemoMind 폰 플러그인.
- conversation_assist_glass.gmp + 인접 manifest.json: 글라스 플러그인과 프로토콜 메타데이터. 리뷰 소스 파일도 함께 제공.
- 이 폴더는 개발 산출물입니다. 공식 MemoMind 설치 ZIP이 아닙니다. Studio에서 폰/글라스 페어를 구성하고 공식 설치 QR/ZIP을 생성하세요.

## 사용 순서

1. 보조 APK 설치 후 열기. 이번 연결된 휴대폰에는 테스트 앱 설치와 기존 Gemma 모델 가져오기를 완료했습니다.
2. 새 휴대폰에서는 **기존 Gemma 모델 가져오기**로 `.litertlm` 파일 선택. 앱 내부로 복사되므로 모델 크기만큼 여유 공간 필요.
3. **연결 키 복사** → **대화 서비스 시작**. 서비스 알림이 표시되며 앱에서 중지할 수 있습니다.
4. Studio로 폰·글라스 플러그인을 설치하고 폰 플러그인 연결 키에 한 번 붙여넣기 → **연결 확인**.
5. **문장 입력으로 AI 테스트**에 고정 문장을 입력해 후보 단어를 확인하거나, 설명할 단어를 직접 입력합니다.
6. 주변 사람에게 자막·기록 중임을 알리고 **듣기 시작**. 음성 원본은 저장하지 않습니다.

안경 자막 화면: **한 번** 선택 이동(단어/자막 다음), **두 번** 선택 실행. 설명 화면: **한 번** 다음 페이지, **두 번** 자막 복귀. **길게** 듣기 시작·정지.

안경 상단은 자막, 하단은 짧은 단어 설명으로 구분합니다. 오래된 도움말은 자막 화면에서 2분 후 숨깁니다. 설명 출처는 폰 화면에 사전/로컬 AI로 구분합니다.

## 자원 절감

- 등록 용어와 영문 약어를 규칙으로 추출합니다. 모든 한국어 전문 용어를 자동 탐지하는 범용 분류기는 아닙니다. 후보에 없으면 폰에서 직접 입력할 수 있습니다.
- HDR, OIS, EIS, MTF, SNR, ISP, API, SDK, LLM, NPU, GPU, EBITDA, 양자화는 사전에서 반환하며 AI 모델을 로드하지 않습니다.
- 미등록 단어의 AI 입력은 최근 문맥 최대 500자와 선택 단어로 제한. 최대 96 출력 토큰, 짧은 비추론 응답.
- 미등록 단어 자동 AI 요청은 최소 45초 간격, 한 번에 하나. 같은 단어는 10분간 자동 재설명하지 않습니다. 모델을 유지해 반복 로딩을 피하므로 첫 요청 후 메모리 사용은 계속될 수 있습니다. 서비스 중지 시 해제합니다.
- 음성은 6초 구간. 대기 큐 최대 두 구간이며 처리 속도가 따라가지 못하면 유실을 숨기지 않고 중단·표시합니다. 무음 구간은 디코딩 후 Whisper를 실행하지 않습니다.
- 대화 기록은 폰 플러그인 저장소에 최근 500개 발언(각 500자), 폰에 최근 30개 표시. 기록 삭제 제공. 임시 음성은 메모리에서만 처리합니다.

## 실제 휴대폰에서 확인한 내용

2026-11-03, SM-S936N, Android 17, RAM 약 12GB.

- 기존 파일 `/sdcard/Download/gemma-4-E2B-it.litertlm`, 2,588,147,712 bytes.
- 앱 내부 모델과 원본 SHA256 일치: `181938105e0eefd105961417e8da75903eacda102c4fce9ce90f50b97139a63c`. 이는 복사 무결성 확인이며 제작사 공식 체크섬 검증은 아닙니다.
- LiteRT-LM 0.18.0 GPU 백엔드에서 한국어 설명 생성 성공.
- Whisper 모델 무결성 확인·JNI 로딩 성공. 테스트 중 Whisper와 Gemma 모델을 같은 프로세스에 로드했습니다.
- Bearer 키 없는 접근 401, 인증 후 상태 조회 정상.
- 6초 무음 Opus 디코딩 성공. AI 요청 중 무음 오디오 요청 200.
- 단일 측정: 사전 HDR 약 73ms. 미등록 CMOS 첫 요청 6.509초(로딩 4.364초 + 생성 2.133초), 모델 유지 후 같은 입력 1.188초(생성 1.168초). ADB 포워딩을 이용한 API 단위 측정이며 안경 마이크→화면 지연 측정이 아닙니다. 입력·발열·메모리에 따라 변합니다.
- Node 논리 테스트 4개 통과, 폰 패키지 및 글라스 GMP 빌드 통과.

## 아직 확인해야 할 부분

**실제 MemoMind 플러그인에서 localhost 통신, 안경 마이크의 실제 발화 인식, 글라스 표시·버튼, 지속 대화 시 자막 처리 속도와 발열은 미검증입니다.** ADB 포워딩 테스트는 MemoMind WebView의 로컬 통신 허용 여부를 증명하지 않습니다. Studio UI 테스트도 수행하지 않았습니다.

음성 구간 경계에서 단어가 잘릴 수 있으며, 멀리 있는 사람의 수음 품질·잡음에 영향을 받습니다. 초저지연 자막, 화자 구분, 번역, 화면 꺼짐 지속 수음을 보장하지 않습니다. AI 설명에는 오류가 있을 수 있으며 사전 설명은 개별 문맥을 추론하지 않습니다.

## 빌드 및 소스

- Android: `integrations/conversation-assist/android`에서 JDK 21을 사용해 `gradlew.bat assembleDebug`.
- Phone: `node PhoneSDK/tools/build-mmpkg.mjs PhoneSDK/examples/conversation-assist dist/MemoConversationAssist-0.1.0.mmpkg`.
- Glass: Python으로 `GlassSDK/build.py build --example conversation_assist_glass`.
- `.gitignore`로 모델·네이티브 라이브러리·빌드 캐시 제외. Android 소스 빌드에는 기존 Whisper 자산 190,085,487 bytes 및 ARM64 libmemo-whisper.so 필요. 새 Gemma 모델은 앱과 별도로 가져옵니다.
- `device_smoke.py`, `latency_benchmark.py`는 연결된 테스트 단말 전용. 토큰은 출력하지 않습니다. 테스트용 포워딩은 검증 후 제거합니다.
- `android/native`의 GGUF JNI는 초기 실험이며 현재 APK에 포함하지 않습니다. 현재 실행 엔진은 LiteRT-LM입니다.

## 라이선스

whisper.cpp/Whisper MIT, LiteRT-LM Apache-2.0 및 각 모델의 배포 조건을 따릅니다. Gemma 모델은 이 배포 폴더에 포함하지 않습니다. APK는 개발용 서명이며 별도 프로덕션 배포 서명과 동일하지 않습니다.


## 폰 플러그인 0.1.1 — 듣기 시작 콘텐츠 차단 수정

설치된 MemoMind의 `assets/memo_gecko_view/host.js`는 `audio.open`에서 page-realm WebSocket을 `ws://127.0.0.1:임의포트/세션경로`로 생성합니다. 0.1.0의 `connect-src`가 보조 APK HTTP 주소만 허용하여 `NS_ERROR_CONTENT_BLOCKED (0x805e0006)`가 발생했습니다.

0.1.1은 `connect-src http://127.0.0.1:18772 ws://127.0.0.1:*`로 수정했습니다. 인터넷 WebSocket이나 임의 외부 서버는 허용하지 않습니다. 폰 패키지 버전은 0.1.1, 보조 APK는 0.1.0, 글라스 GMP는 버전 1입니다.

**기존 폰 플러그인을 Studio에서 MemoConversationAssist-0.1.1.mmpkg로 업데이트한 뒤 플러그인을 종료·재시작하세요.** 기존 글라스 GMP/manifest는 그대로 사용합니다. 보조 APK·모델 재설치는 필요 없습니다. 같은 플러그인 ID를 유지하며 기록과 연결 키를 삭제하지 마세요.

CSP 회귀 테스트를 포함해 Node 테스트 5개 통과 및 MMPKG 생성 확인. 실제 MemoMind에 수정본을 설치한 뒤 녹음 시작 성공과 실제 음성 수신은 추가 확인해야 합니다.


# 0.2.0 — 연속 자막 갱신 버전

## 반드시 업데이트할 파일

1. MemoConversationAssist-0.2.0.apk를 기존 보조 앱 위에 업데이트 설치합니다. 삭제 후 재설치하지 마세요. 기존 Gemma 모델과 연결 키를 유지합니다.
2. Studio에서 폰 플러그인을 MemoConversationAssist-0.2.0.mmpkg로 업데이트한 뒤 종료·재시작합니다.
3. 글라스 GMP와 인접 manifest.json은 기존 버전 그대로 사용합니다.
4. 보조 앱에서 서비스 시작 → 폰 플러그인 연결 확인 → 듣기 시작. 모델 준비 완료 후 녹음 채널을 엽니다.

## 변경점

- 6초 수집을 2초(20ms 프레임 100개)로 단축. 녹음을 멈추지 않고 다음 구간을 계속 받아 처리합니다.
- Whisper small Q5_1에서 경량 base Q5_1 다국어 모델로 변경. 공식 배포처 LFS SHA256과 다운로드 파일 일치 확인: 422f1ae452ade6f30a004d7e5c6a43195e4433bc370bf23fac9cc591f01a8898, 59,707,625 bytes. APK에 포함하므로 별도 다운로드 불필요.
- 인식 엔진을 빔 탐색 5개에서 greedy 1개, 최대 출력 64토큰, 최대 CPU 4스레드로 변경. 한국어로 고정합니다.
- 최초 음성이 들어오기 전에 /prepare로 모델을 준비하여 첫 자막에 모델 로딩 시간을 더하지 않도록 구성했습니다. 모델 준비 자체의 대기 시간은 남습니다.
- 실제 수신 음성 시간과 인식 상태 표시. 8초 동안 음성이 안 들어오면 ‘안경 음성 수신 대기’ 안내.
- 네이티브 Gecko 음성 채널용 ws://127.0.0.1:* CSP 허용 유지.
- 상·중·하 설정 없이 단어 후보 → 사전 또는 로컬 AI 설명 기능 유지. 설명 중에 듣기를 의도적으로 멈추지 않습니다.

## 지연·정확도에 대한 한계

**매 단어가 즉시 표시되는 스트리밍 디코더가 아닙니다.** 2초 구간마다 인식 결과를 갱신하며 실제 표시 지연에는 음성인식 시간, 대기열, 안경 전송 시간이 추가됩니다. 2초 이내 표시를 보장하지 않습니다. 짧은 구간과 경량 모델·greedy 탐색은 인식 정확도에 영향을 줄 수 있으며 구간 경계에서 단어가 잘릴 수 있습니다.

처리 속도가 음성 속도를 따라가지 못해 큐가 두 구간을 초과하면 중단하고 안내합니다. 음성 데이터를 몰래 버려 빠르게 보이게 하지 않습니다. 호스트의 백그라운드/화면 꺼짐/블루투스 정책에 따라 중단될 수 있습니다.

## 검증

- 음성 분할·프레임 경계·꼬리 flush·중단 시 데이터 폐기·CSP 등 Node 테스트 7개 통과.
- ARM64 네이티브 Whisper 엔진, Android APK, 폰 MMPKG 빌드 통과.
- APK 안의 모델·네이티브 라이브러리와 버전 메타데이터 확인.
- 이 수정 시점에 휴대폰 ADB 연결이 없어 새 엔진의 실기기 로딩·실제 말소리 정확도·연속 처리 속도·안경 표시는 미검증입니다. 이전 0.1.x의 무음 디코딩·Gemma 설명 성공 결과를 이 버전의 전체 동작 검증으로 간주하지 않습니다.

실제 안경과 폰에서 수신 시간이 증가하는지 먼저 확인하세요. 수신 시간은 증가하지만 자막이 없으면 인식 단계, 수신 시간 자체가 없으면 녹음/연결 단계를 확인해야 합니다.


# Memo 자동 대화 도움 0.3.0

## 사용자가 원하는 동작

사용자는 대화만 합니다. 안경은 대화 자막을 계속 갱신하고, AI가 최근 문맥을 읽어 이해나 답변에 필요한 도움 하나를 스스로 판단해 표시합니다. 단어·질문 선택과 상·중·하 설정은 없습니다. 개인의 경험·회사 수치·약속은 지어내지 않도록 지시합니다. 답변을 외부로 보내거나 대신 발화하지 않습니다.

- 자막: 2초 음성 구간을 연속 인식. 실제 표시 지연은 2초 수집 외에 인식·대기열·전송 시간이 더해집니다. 단어 단위 즉시 스트리밍을 보장하지 않습니다.
- 도움: 최근 대화 최대 500자. AI가 용어, 답변 힌트 또는 도움 불필요를 판단합니다. 도움이 없으면 아무것도 표시하지 않습니다.
- 최소 10초 간격, 새 문맥이 있을 때만 판단. 음성 대기열이 있으면 판단을 미룹니다. 한 번에 한 AI 작업, 같은 종류·주제는 10분간 중복 표시 방지.
- 도움 생성 중에도 수음은 유지. 도움은 자막 아래 별도 영역에 표시하며 2분 후 자막 화면에서 숨깁니다. 호스트 중단·연결 끊김·처리 속도 부족 때는 중단·안내합니다.
- 고정 사전은 AI가 고른 용어의 정확한 정의를 보완합니다. 자동 판단 자체는 로컬 Gemma가 수행합니다.

## 설치

이번 연결된 SM-S936N에는 보조 APK 0.3.0을 업데이트했습니다. 기존 Gemma 모델과 연결 키를 보존했습니다.

1. 다른 기기에서는 MemoConversationAssist-0.3.0.apk 설치. 기존 앱이 있으면 업데이트 설치하고 삭제하지 마세요.

# Memo 회의 0.8.1 — 16KB 네이티브 정렬 수정

0.8.0의 GPU 동적 라이브러리 5개에 4KB LOAD 정렬이 남아 Android 호환성 경고가 표시되었습니다. JNI 파일에만 적용했던 옵션을 CMake 전체 shared/module 타깃에 적용했습니다. max-page-size=16384와 common-page-size=16384를 함께 사용하여 RELRO 경계도 정렬했습니다.
구글 공식 LiteRT-LM 0.18.0/0.18.1의 사전 빌드 파일은 LOAD가 16KB였으나 RELRO 끝이 정렬되지 않았습니다. 0.19.0 공식 파일에서 두 경계를 확인한 뒤 SDK를 교체했습니다. 사전 빌드 바이너리를 임의 수정하거나 경고 숨기기 설정을 넣지 않았습니다.

## 검증
최종 APK의 arm64 공유 라이브러리 7개 전체에 대해 LOAD p_align >= 16384, 주소/파일 오프셋 합동 조건, RELRO 끝 정렬 검사 통과. zipalign -c -P 16 -v 4 통과. Android JUnit7개 통과.
실제 휴대폰에서 EXAONE CPU 응답, OpenCL GPU 응답, LiteRT-LM 0.19 Gemma 자동 도움 JSON 및 회의 요약 생성 성공. 이는 엔진 동작 검사이며 답변 내용의 사실 정확성 전체를 보증하는 시험은 아닙니다.
휴대폰 getconf PAGE_SIZE는 4096입니다. APK 구조 검증과 4KB 실기기 회귀 시험을 완료했으며 별도 16KB 커널 기기에서의 전체 실행 시험은 아직 하지 않았습니다.

## 업데이트
MemoConversationAssist-0.8.1.apk를 기존 앱 위에 설치합니다. 기존 Gemma/EXAONE 파일, 모델 선택, 회의 기록을 유지합니다. 폰 플러그인 0.6.0과 글라스 GMP는 변경 없습니다. GPU/모델 선택 방법은 0.8.0과 동일합니다.

정렬 재검사: python integrations/conversation-assist/verify_16kb.py <APK경로>. LOAD·RELRO JSON은 elf-16kb-verified.json, 기기 응답 기록은 alignment-device-verified.json.

## 변경
전문 분야에 한정하지 않고 최근 미해결 질문·문의에 reply 답변 도움을 우선 제안합니다. 알 수 없는 개인·회사 내부 정보는 추측하지 않고 확인 방법이나 되물을 질문을 제안하도록 지시합니다. 질문이 없으면 전문 용어 설명을 제공하고 불필요한 도움은 생략합니다. AI 판단과 답변이므로 모든 질문 감지·사실 정확성을 보장하지 않습니다.
AI 요청 시작 이후 새로 확정된 자막이 0~9개이면 도움 표시 가능, 10개 이상이면 생략합니다. 확정 문장 ID를 사용해 같은 타임스탬프로 수신된 여러 문장도 계산하며, 같은 문장의 수정/부분 자막은 추가 발언으로 세지 않습니다. 결과 도착 및 저장 직후 표시 전에 재확인합니다.
짧은 질문도 분석 대상에 포함했습니다. 자동분석 최소10초 간격, 중복 억제, 5초 도움 카드 표시는 유지합니다.

## 적용
APK0.8.2는 휴대폰에 업데이트 설치합니다. MemoMind Studio의 폰 플러그인도 MemoConversationAssist-Phone-0.6.1.mmpkg로 교체 후 종료·재시작해야 새 발언10개 기준이 적용됩니다. 글라스 GMP는 변경 없습니다. APK에서 자동 연결 시작 후 폰 플러그인을 사용합니다.

## 검증
폰 논리 테스트16개 통과(9개/10개 경계, 같은 시각 문장, 짧은 질문 포함). Android JUnit7개 통과. 최종 APK 모든7개 네이티브 라이브러리16KB LOAD·RELRO 검사 통과.
실제 휴대폰의 별도 Gemma 테스트 사본에서 일반 질문/내부 미공개 예산 질문 모두 reply로 응답하고, EXAONE GPU도 일반 질문에 reply 응답 확인.
현재 등록된 LiteRT 모델은 사용자가 가져온 Qwen3-0.6B입니다. 초기 시험에서 한국어 답변 부정확·질문 판단 누락이 확인되어 프롬프트를 보완했습니다. 최종 프롬프트의 실기기 성공 사례는 Gemma/EXAONE이며 Qwen 성공을 확인했다고 주장하지 않습니다. 신뢰성 우선이면 Gemma를 권장합니다. 선택 모델·파일은 임의 변경하지 않았습니다.

## 저장
원문·회의록·모델 파일·연결 설정은 유지합니다. 테스트용 임시 Gemma 사본만 제거합니다. Qwen 및 EXAONE 파일을 지우지 않습니다.


# Memo 회의 0.10.0

## 휴대폰만으로 회의 기록
홈 → ‘휴대폰 마이크로 회의 시작’ → ‘듣기 시작 / 재개’. MemoMind 앱·폰/글라스 플러그인 없이 사용합니다. 마이크 권한을 허용하세요. 실시간 자막을 표시하고 전체 원문을 APK 회의 저장소에 기록합니다. 일시정지는 같은 회의에 이어 저장하며 ‘회의 완료 · 회의록 생성’을 누르면 선택한 로컬 AI로 회의록을 만듭니다. 원본 음성 파일은 저장하지 않습니다.
기록 중 포그라운드 알림과 WakeLock을 사용하며, 일시정지/종료/마이크 오류에서 해제합니다. 글라스와 휴대폰 녹음을 동시에 시작하지 않도록 제한합니다. 먼저 진행 중인 듣기를 정지한 후 입력원을 바꾸세요. 일시정지 후 입력원을 변경해도 완료 전에는 같은 회의로 이어집니다. 새 회의를 만들려면 기존 회의를 완료하세요.

## 회의록 문서 양식
카드 UI가 아니라 A4 인쇄용 문서입니다. 제목·회의 날짜/시간, 핵심 요약, 주요 논의, 결정 사항, 실행 과제 표(업무/담당자/기한), 확인 사항을 문서로 표시합니다. 내용이 없거나 AI가 구분하지 못한 항목은 임의로 지어내지 않습니다. 기존 회의록 텍스트는 섹션 제목을 해석해 문서화하고 내용을 보존합니다. 완전히 자유 형식인 기존 문서는 ‘회의록 안내’ 항목에 남을 수 있습니다. 새 회의록/다시 생성부터 실행 과제의 표 형식을 명시적으로 요청합니다.
Lucide 공식 저장소 SVG 아이콘5개를 앱에 내장했습니다. 인터넷 없이 같은 아이콘을 지속 사용하며 HTML 저장/인쇄에도 포함합니다. 라이선스는 licenses/Lucide-LICENSE.txt.
AI 회의록 탭 → ‘문서 전체 화면 · 확대’: A−/A＋, 손가락 확대. ‘양식 문서 저장’: 스타일과 아이콘이 내장된 HTML 파일. ‘PDF · 인쇄’: Android 인쇄 창에서 ‘PDF로 저장’을 선택해 저장합니다. TXT 저장은 원래 텍스트로 별도 유지합니다. PDF가 회의 완료 시 자동으로 생성되는 방식은 아닙니다. 새 회의록 생성 시 내부 minutes.html도 저장됩니다. HTML 내보내기는 현재 표시된 미리보기를 문서화하므로 매우 긴 회의록의 20만자 화면 한도를 넘는 전체 원문/요약은 TXT로 내보내세요.

## 모델 부하 비교
MODEL_RESOURCE_COMPARISON.md 및 model-resource-device-verified.json 참조. 같은 질문3회 GPU 생성 시험:
Qwen: 앱 최대PSS 2.76GiB, 생성 평균0.92초.
Gemma: 2.16GiB, 평균1.99초.
EXAONE: 2.50GiB, 평균4.05초.
이는 한 프로세스의 PSS 표본이며 GPU 전체 메모리와 같지 않습니다. USB 충전 중 순차 시험이므로 배터리 소모량/전력/장시간 발열의 순위를 뜻하지 않습니다. 빠른 Qwen에서도 이전 시험에서 부정확한 답변과 질문 누락이 있었으므로 속도와 품질을 함께 판단하세요. 현재 선택 모델은 유지했습니다.

## 검증 및 설치
0.10.0 APK를 기존 앱 위에 설치했고 versionCode15 확인. Android JUnit9개 통과, 전체7개 네이티브 라이브러리16KB LOAD/RELRO 및 zipalign 검사 통과. 테스트 전용 컴포넌트는 최종 APK에 포함하지 않습니다.
실기기 PhoneMicrophone→NativeKoreanSpeech 경로에서4초간62400 PCM샘플 수신/정상 종료 확인. 이는 장시간 회의나 소음 환경의 인식률 검증이 아닙니다.
고정 문서 예제의 아이콘·A4 문서 렌더링 및 Android 인쇄1페이지 미리보기를 실제 휴대폰에서 확인했습니다. 최종 PDF 파일 선택·저장은 사용자가 인쇄 창에서 진행합니다. 공유 예제는 실제 사용자 회의가 아닙니다.
기존 사용자 기록·모델 파일 보존. 시험용 Gemma 임시 사본만 제거했습니다. 폰 플러그인은0.6.1, 글라스 GMP는 기존 것과 동일합니다. 휴대폰 전용 사용에는 플러그인이 필요하지 않습니다.


# Memo 회의 0.12.0

## 페이지 구성
상단 ‘회의록 / 휴대폰 회의 / 설정’ 카테고리를 터치하거나 빈 화면·일반 본문 영역에서 좌우로 밀어 이동합니다. 카드 영역은 삭제/공유 스와이프가 우선하며 검색 입력란·문서 확대 영역은 페이지 이동에서 제외합니다. 세 페이지는 좌우 끝에서 순환하지 않습니다. 다른 페이지로 이동해도 진행 중인 휴대폰 녹음을 자동으로 중지하지 않습니다. 녹음 중지는 휴대폰 회의 페이지의 일시정지 또는 설정의 서비스 중지를 사용합니다.
회의록: 이미지 기준 상단 소개·현재 날짜/총 기록 수·달력·회의 기록 검색·날짜별 목록.
휴대폰 회의: 자막 영역, 별도 AI Tip, 듣기 시작/재개·일시정지·회의 완료. MemoMind 플러그인 없이 사용합니다.
설정: 모델 관리, GGUF 연산 장치, 휴대폰 AI Tip 켜기/끄기, 문서 글자 크기, 기록 삭제/공유 안내, HTML/PDF 저장 설명, 안경 자동 연결, 연결 키 복구, 녹음·저장 안내, 서비스 중지, 앱 정보.

## 둥근 삭제·공유 아이콘
왼쪽 밀기: 붉은 원형 휴지통 아이콘 → 눌러 삭제 확인.
오른쪽 밀기: 녹색 원형 공유 아이콘 → 눌러 Android 공유 앱 목록.
Lucide 공식 SVG를 내려받아 Android 벡터로 변환해 내장했습니다. 라이선스는 licenses/Lucide-LICENSE.txt. 오프라인에서도 표시됩니다. 스와이프만으로 삭제/공유하지 않습니다.

## 휴대폰 AI Tip
현재 선택한 로컬 AI 엔진으로 자막의 최근500자 문맥을 분석합니다. 질문은 reply, 어려운 용어는 term, 불필요하면 none. 용어 사전에 정의가 있으면 보완합니다. 최소10초 간격, 동일 문맥 재분석 억제, 같은 주제 중복 억제, 결과 도착 시 새 확정 발언10개 이상이면 생략합니다. 자막 저장과 별도 스레드로 처리하고 AI 작업이 바쁘면 양보합니다. 페이지를 떠나거나 듣기가 정지된 경우 이전 결과를 표시하지 않습니다. 긴 Tip은 눌러 전체 내용을 봅니다. AI 판단·정확도는 모델에 따라 달라 모든 질문에 답한다고 보장하지 않습니다.

## 검증
Android 빌드/JUnit10개 통과. 실제 휴대폰의 고정 UI 시험에서 세 카테고리 표시·페이지 좌우 이동·휴대폰 AI Tip 영역·카드 양방향 스와이프 후 아이콘 클릭 콜백 확인. 사용자 회의를 삭제하거나 외부로 발송하지 않았습니다. 실제 연속 발화와 동시에 자동 Tip이 표시되는 장시간 시험은 별도입니다. 최종 APK는 테스트 컴포넌트 제외, 16KB LOAD/RELRO 및 ZIP 정렬 검사 통과.
기존 회의·모델·연결 키 유지, 폰 플러그인0.6.1과 글라스 GMP 변경 없음.


# Memo 회의 0.13.0
앞서 공유된 MemoMind 화면의 밝은 회색 배경·흰 카드·검은 강조 버튼·둥근 모서리를 참고하여 앱 화면 색상과 여백을 맞췄습니다. 기존 녹색 계열 앱 강조색을 중립 색상으로 정리했습니다. 시스템 sans-serif를 본문400/제목600/버튼500 굵기, 작은 음수 자간과 일정한 줄 간격으로 적용했습니다. MemoMind의 비공개 폰트를 추출·복제하지 않았으므로 동일 폰트라는 의미는 아닙니다. 문서 인쇄 양식과 글라스 화면은 유지했습니다.
카테고리 터치/좌우 스와이프에300ms 가감속 슬라이드를 적용했습니다. 드래그 시 현재 페이지가 손가락 방향으로 움직이고, 손을 놓으면 다음 페이지가 들어옵니다. 전환 중 중복 터치를 막고 완료 후 이전 화면 비트맵을 해제합니다. 시스템 애니메이션 비활성화 설정을 따르며 끝 페이지에서 더 밀면 제자리로 복귀합니다. 회의 카드 삭제·공유 제스처는 페이지 이동과 분리합니다.
검증: Android JUnit10개 및 빌드 통과. 실제 휴대폰에서 카테고리 전환·스와이프 목표 페이지·전환 종료 후 임시 오버레이 제거 확인. 화면 녹화로 프레임률/버벅임을 정량 측정한 것은 아닙니다. 네이티브16KB 정렬 및 ZIP 검사 통과. 기존 회의·모델·연결 설정 유지, 폰/글라스 플러그인 변경 없음.
