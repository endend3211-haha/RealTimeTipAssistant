# 모델별 휴대폰 부하 — SM-S936N

각 모델을 GPU로 실행하고 같은 질문을 연속3회 생성했습니다. 순서는 Qwen→Gemma→EXAONE입니다. 준비 시간은 생성 시간에서 제외합니다. 순서·발열 영향을 제거한 장시간 부하 시험이 아닙니다. PSS는 프로세스의 공유 메모리를 비례 배분한 값으로 전체 GPU 메모리/전체 시스템 RAM과 같지 않습니다. 500ms 주기로 표본을 수집해 순간 최대치를 놓칠 수 있습니다. CPU%는 프로세스 CPU시간 / 경과시간으로 1코어=100% 기준이며 GPU%가 아닙니다. 기기는8코어입니다. 배터리 온도는 USB 충전 중 값이고 SoC온도·소비전력·배터리 소모율을 뜻하지 않습니다.

|모델|최대 앱PSS|CPU(1코어=100%)|생성 평균|배터리 온도|
|---|---:|---:|---:|---:|
|Qwen3-0.6B LiteRT GPU|2.76 GiB|59.7%|0.92초|35.1→35.1℃|
|Gemma E2B LiteRT GPU|2.16 GiB|31.9%|1.99초|35.1→36.6℃|
|EXAONE 2.4B OpenCL GPU|2.50 GiB|54.2%|4.05초|36.6→38.5℃|

모두 Android thermalStatus=0(열 제한 보고 없음)이었습니다. Qwen 파일은 작아도 실행 버퍼 때문에 PSS가 가장 컸습니다. 이번 질문 응답 길이·판단 품질도 달라 속도만으로 모델 품질을 비교할 수 없습니다. GPU 사용률·전력은 이 시험에서 측정하지 않았습니다. 최근 질문 정책 변경 후 시험이므로 이전 속도 표와 직접 합치지 마세요.
