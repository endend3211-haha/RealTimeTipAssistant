# Memo 회의 0.16.0 — AI 기억 질문

설정 화면의 별도 ‘AI 기억’ 카드 > ‘AI 기억 열기’를 누릅니다. 텍스트를 입력하거나 ‘음성 질문’을 눌러 휴대폰 마이크로 한국어 질문을 말합니다. 인식 문장을 확인·수정하고 ‘질문하기’를 눌러 제출합니다. 음성으로 자동 제출하지 않습니다. 입력 중 ‘말하기 완료’를 누를 수 있습니다.

선택한 로컬 AI(.litertlm/GGUF)를 그대로 사용하며, 저장된 최근 7일 알림에서 검색된 최대 5건의 발췌를 바탕으로 답합니다. 날짜·제목/대화방·발신 정보·원문 발췌를 별도 표시합니다. 오늘·어제·그제 문구는 기기 현지 날짜로 범위를 좁힙니다. 전체 데이터를 모두 분석한 답변이 아니므로 표시된 검색 근거를 확인하세요. 관련 자료가 없으면 모델을 실행하지 않고 안내합니다. 모델의 근거 번호가 범위를 벗어나거나 형식이 깨지면 답변을 표시하지 않고 원문 확인을 안내합니다. 번호 검증만으로 답변의 모든 사실 정확성을 보장하지 않습니다.

카카오톡 수집 및 AI Tip 참고 스위치가 켜져 있어야 합니다. 다른 AI 작업이 사용 중이면 잠시 후 재질문을 안내합니다. 새 질문·음성·답변 기록은 별도 파일로 저장하지 않습니다. 원문 저장소는 기존 앱 내부 AI/kakao.db를 사용합니다.

음성 질문은 Android 기기 내 한국어 음성인식과 RECORD_AUDIO 권한을 사용합니다. 한국어 모델이 없으면 기기 음성인식 언어 설정 안내를 표시합니다. 음성 회의 중에는 마이크 충돌 방지를 위해 일시정지를 안내합니다. 화면을 닫거나 앱을 벗어나면 질문용 인식기를 해제합니다. 기존 회의 기록에 질문 음성을 추가하지 않습니다.

검증: JUnit 14개 통과(기존 10개 + 근거 없는 모델 호출 차단·출처 번호 검증·잘못된/무근거 답변 차단·원문 JSON 이스케이프 4개). SM-S936N 기기에서 합성 데이터의 주제/발신/대화방/오늘·어제 검색, 별도 카드와 빈 검색 결과 화면, 선택된 gemma-4-E2B-it.litertlm의 실제 근거 답변을 확인했습니다. 한국어 음성 버튼·인식 결과 문장 처리·권한/언어 오류 안내·실제 기기 내 마이크 준비/해제를 확인했습니다. 사용자 발화의 전체 인식 정확도는 별도 실사용 확인이 필요합니다. 개인 알림 내용을 테스트 출력에 기록하지 않았습니다.
