# 카카오톡 AI 기억 (0.15.0)

설정 > 카카오톡 AI 기억 · AI 폴더에서 수집 스위치를 켜고 알림 접근 권한을 직접 허용합니다. 기본값은 꺼짐입니다. 새로 전달되는 com.kakao.talk 알림 텍스트만 수집합니다. 다른 앱, 그룹 요약 알림, 인증번호/OTP 문구는 제외합니다. 숨겨진 본문·과거 전체 대화·사진·첨부파일은 가져오지 않습니다. 일반 알림과 MessagingStyle 메시지를 지원하며 동일 메시지의 알림 갱신을 중복 제거합니다. 일반 알림에서 같은 키·같은 날짜·같은 본문이면 한 번만 보관하므로 이 형식으로 전달된 동일 문장 반복을 구별하지 못할 수 있습니다.

저장 위치: 앱 전용 `/data/user/0/com.mcnex.conversation/files/AI/kakao.db`. 원문, FTS4 외부 콘텐츠 색인, 일별 AI 정리와 원문 번호를 같은 SQLite DB에 보관합니다. 일반 파일 관리자의 공용 AI 폴더가 아닙니다. 데이터는 외부 서버로 업로드하지 않으며 모델 파일·회의록 저장소와 구분합니다. 앱 삭제 또는 데이터 초기화 시 사라집니다.

보관: 기기 현지 날짜로 오늘 포함 7일. 알림 수집, 검색, 설정/앱 진입 및 약 30분 주기 OS 작업에서 만료 원문과 요약을 논리 삭제합니다. Android 절전·강제 종료에 따라 작업 실행은 지연될 수 있지만 검색 전에 만료 자료를 정리합니다. 삭제는 포렌식 복구 불가능 보장을 의미하지 않습니다. 수집 중지는 기존 자료를 즉시 삭제하지 않으며 전체 삭제 버튼을 따로 제공합니다.

검색: 최근 대화 키워드로 FTS4 검색, 한국어 조사 등에 대해 LIKE 보완. 관련 원문 최대 3건, 각 300자를 휴대폰/글라스 AI Tip에 전달합니다. 임베딩 모델을 별도로 상주시켜 RAM을 늘리지 않습니다. 알림은 신뢰할 수 없는 과거 자료로 표시하고 내부 지시 실행을 금지하며 현재 질문과 관련된 사실만 참고하도록 프롬프트를 구성합니다. AI의 사실 판단·출처 표기는 모델에 따라 오류가 있을 수 있습니다.

일별 정리: 전날까지의 자료를 800자 안팎 조각으로 나눠 원문 번호와 연결한 AI 정리를 저장합니다. 충전 중·유휴 상태에서 약 30분 주기 작업마다 한 조각을 처리합니다. 실제 음성 회의 중이거나 AI가 사용 중이면 연기합니다. OS 상태와 데이터량에 따라 완료 시각은 보장하지 않습니다. 일별 정리 보기는 최근 30조각을 표시합니다. AI Tip은 요약의 오류가 전파되지 않도록 관련 원문을 직접 검색합니다. 삭제·스위치 변경 도중 실행되던 작업의 이전 결과가 다시 저장되거나 표시되지 않도록 세대 번호를 확인합니다.

검증: 기존 JUnit 테스트 + SM-S936N 격리 캐시 DB 합성 알림 기기 테스트(일반 알림/MessagingStyle, 앱 제한, 중복 제거, 한국어/FTS 검색, 7일 만료 원문·색인·요약 삭제, OFF 시 수집·참고 차단, 일별 조각 캐시, 전체 삭제 후 이전 작업 재저장 방지, 설정 항목 표시). 실제 카카오톡 알림 수신 및 자연스러운 AI 답변 품질은 사용자가 알림 접근을 허용한 뒤 확인해야 합니다. 실제 개인 알림을 테스트에 사용하지 않았습니다.
