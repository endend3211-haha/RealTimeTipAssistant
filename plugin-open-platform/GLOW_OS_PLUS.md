# GLOW OS Plus 1.0.7

폰 앱 표시 이름, 화면 제목, 글라스 상단 표기를 GLOW OS Plus로 맞췄습니다. 배포 파일명도 변경했습니다. 내부 ID는 기존과 같아 업데이트 시 기존 설정을 유지할 수 있습니다.

## 설치 파일
- 01_Phone/GLOW-OS-Plus-Phone-1.0.7.mmpkg
- 02_Glass/glow_os_plus_glass.gmp 및 같은 폴더의 manifest·review 파일

MemoMind Studio에서 위 폰·글라스 파일을 페어로 선택해 패키징 후 설치하세요. 글라스 표시 브리지의 기능은 이전과 같으며 파일명·표시 이름을 변경한 버전 4입니다. 기존 글라스 버전 3도 같은 프로토콜을 제공합니다. ZIP은 전달용이며 Studio 공식 설치 패키지를 대신하지 않습니다. 별도 APK는 포함하지 않습니다.

## 폰 화면 정리
홈은 안경 홈 열기, 뉴스·주식·게임 실행 카드만 우선 표시합니다. 날씨·메모·사용 안내는 접힌 상태로 제공합니다. 뉴스·주식의 연결 설정·안경 미리보기도 펼쳐서 사용합니다. 주식 보유 수량·평균단가는 보유 정보 수정에서 입력합니다. 연한 배경과 녹색 포인트, 통일된 글꼴·버튼·아이콘으로 정리했습니다.

## 안경 조작
메뉴 순서: 날씨 → 뉴스 → 주식 → 게임 → 세계 시계 → 계산기 → 메모. 화면 밖 메뉴가 있는 방향에만 화살표를 표시합니다. 길게 누르기는 Glow 홈입니다. 뉴스는 한 번 선택·두 번 이전, 주식은 한 번 이동·두 번 실행입니다. 게임은 폰 테트리스로 실행하며 고개 좌우 이동·한 번 회전·두 번 즉시 낙하·길게 홈입니다.

뉴스·주식은 기존 공개 중계를 사용합니다. 현재 위치 날씨는 위치 권한이 필요하며 실행 중 5분 간격으로 갱신합니다. 게임은 앱이 백그라운드거나 다른 화면으로 전환되면 멈춥니다. Bluetooth 상태에 따라 안경 화면 전송 지연이 생길 수 있습니다.

## 검증
실제 Web SDK와 모의 호스트/네트워크 브라우저에서 접힌 설정을 펼쳐 사용하는 동작, 뉴스·주식·보유 정보·게임·위치·홈 복귀를 확인했습니다. 430px 폰 너비의 홈·뉴스·주식 화면을 캡처해 확인했습니다. 폰 패키지와 이름을 변경한 글라스 빌드를 통과했습니다. 실제 MemoMind 앱과 안경에서의 UI·게임 전송 속도는 추가 확인이 필요합니다.
