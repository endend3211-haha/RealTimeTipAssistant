# Memo 뉴스 웹 기사 리더 0.2.0 — RSS 미사용

## 바뀐 점
공개 뉴스 웹페이지를 HTTPS로 읽는 중계서버와 폰·글라스 플러그인 구성입니다. RSS, 별도 APK, localhost 서비스, 사용자 뉴스 API 키, AI 모델이 필요하지 않습니다.

운영 서버: https://memo-public-news-relay.plaincoach2.chatgpt.site
2026-11-04 공개 조회 전환을 완료했습니다. 별도 로그인·인증키 없이 플러그인이 읽을 수 있습니다. 운영 서버 및 실제 브라우저 직접 연결 검증을 통과했습니다. 서버 비밀키·서비스 토큰은 이 ZIP에 넣지 않았습니다.

## 언론사와 기사
서버가 공개 목록과 기사 본문 수집을 확인한 언론사만 약5분 캐시 단위로 표시합니다. 로컬 Worker 검증에서는 전자신문·디지털타임스·MBN·매일경제·동아일보가 성공했지만, 실제 운영 Worker의 첫 확인에서는 전자신문·동아일보가, 이후 플러그인 연결 확인에서는 전자신문·MBN·매일경제·동아일보가 성공했습니다. 서버 환경별 응답 차이가 있어 운영 결과를 우선합니다. JTBC 등 본문 추출 실패 사이트는 표시하지 않습니다. 목록은 접속 상황에 따라 변동됩니다.

언론사 홈/분야 페이지의 기사 링크를 읽으므로 전체 과거 뉴스 검색이 아닙니다. 검색어는 현재 선택한 언론사에서 수집한 목록을 필터링합니다. 제목에 없는 주제를 모든 기사 본문에서 검색하는 기능은 아닙니다. 기사 날짜를 목록 페이지에서 얻지 못하면 상세를 열 때 확인합니다.

본문은 선택 시 서버가 HTTPS로 읽어 HTML의 기사 영역/구조화된 NewsArticle/Readability로 추출합니다. 출처·원문 링크를 표시하고, 로그인·유료·차단 또는 추출 불가 기사는 제외합니다. 선택 시 제외 대상임이 확인된 기사는 목록에서 제거합니다. 뉴스 본문은 AI가 생성하지 않습니다. 매우 긴 기사는 일부를 표시하고 안내합니다.

## 설치
1. 압축을 해제합니다. 전체 MemoMind SDK/Studio를 열고 워크스페이스를 새로고침하거나 Import application package로 두 파일을 가져옵니다.
2. 폰: 01_Phone/MemoNews-Phone-0.2.0.mmpkg — ‘Memo 뉴스 리더 웹 기사 0.2.0’, com.mcnex.news.phone.
3. 글라스: 02_Glass/news_reader_glass.gmp — ‘Memo News Glass’, com.mcnex.news.glass. manifest.json과 review.json/review-source.enc를 같은 폴더에 유지합니다.
4. 두 컴포넌트를 선택하고 Studio Packaging 완료 후 현재 QR을 사용합니다. 이 공유 ZIP 자체는 Studio가 만든 설치 ZIP이 아니므로 휴대폰에 로컬 ZIP으로 직접 가져오지 않습니다.
5. 안경을 착용·켜고 MemoMind 앱에서 연결합니다. PC와 폰을 같은 접근 가능한 LAN에 연결합니다.
6. MemoMind > 설정 > Memo Lab > Developer Workspace에서 Studio QR을 스캔해 권한을 허용하고 실행합니다.
7. 기존 회의 플러그인과 글라스 페어를 섞지 마세요. 뉴스 전용 플러그인입니다. APK 설치는 필요 없습니다.
MemoMind의 개발자 계정·앱 소유권 검사는 별도로 적용됩니다. 다른 계정이 이 ZIP/QR만으로 실행 권한을 얻는 것은 아닙니다.

## 조작
- 왼쪽 언론사 / 오른쪽 기사 목록. 언론사 선택 시 그 언론사의 기사 목록을 가져옵니다.
- 고개 좌우: 언론사·기사 영역 포커스 전환. 상하: 해당 영역의 항목 이동.
- 안경 버튼 한 번: 언론사 선택 또는 기사 상세 열기. 상세에서는 다음 페이지.
- 두 번: 상세 → 목록 → 언론사 영역. 길게: 언론사 영역.
- 상세에서 고개 상하/좌우: 이전·다음 페이지. 반복 오작동 방지를 위해 중립 복귀와 약0.8초 간격을 사용합니다.
- 폰의 이전/선택/다음/뒤로와 직접 언론사/기사 터치도 지원합니다.
- 폰에서 관심 키워드를 추가·삭제하고 검색할 수 있습니다.

## 운영과 저장
서버는 OpenAI Sites의 Cloudflare Workers 환경에서 실행합니다. PC·휴대폰을 켜두는 중계 방식이 아닙니다. 기사 목록은 약5분, 본문은 약15분 캐시하며 캐시가 비면 요청 시 다시 수집합니다. 별도 주기 실행이나24시간 사람이 모니터링하는 서비스를 설정한 것은 아닙니다. 언론사 구조·정책 변경 시 유지보수가 필요합니다.

서버는 미리 정한 언론사 HTTPS 주소와 기사 경로만 읽으며 임의 URL/내부망 주소는 거부합니다. robots 경로 정책을 확인하고 인증·유료·접근 차단을 우회하지 않습니다. 동일 실행 인스턴스의 IP별 요청 제한과 캐시를 적용합니다. 전역 분산 과금 한도를 보장하는 기능은 아닙니다.

개인 회의록·카카오톡 알림·음성은 이 뉴스 서버로 전송하지 않습니다. 플러그인의 캐시는 제한된 분량의 기사 발췌로 저장하고24시간 이내 자료만 복구합니다. 캐시 삭제 버튼을 제공합니다. 음성 검색·하이 메모 호출·음성 낭독은 포함하지 않습니다.

## 검증
- 서버 테스트6개: 허용 HTTPS 경로, robots, HTML 링크 필터링, 유료 기사 제외, 구조화된 본문, MBN 메뉴 제거.
- 폰 핵심 테스트8개 및 모의 SDK Host 브라우저 UI: 동적 언론사·검색·본문·유료 기사 제거·고개·버튼·늦은 응답 무시.
- 로컬 Worker 실제 웹 기사 및 브라우저 UI, 운영 서버의 실제 기사 목록/본문 수집을 확인했습니다. 공개 전환 후 인증 없는 운영 API와 실제 브라우저의 폰 플러그인 직접 연결도 확인했습니다. 기사 수집 네트워크는 모의하지 않았고, 안경 표시·입력 Host만 모의했습니다.
- 실제 MemoMind 앱/안경의 설치·고개 감도·광학 가독성·잠금 중 실행은 별도 실기기 확인이 필요합니다.
