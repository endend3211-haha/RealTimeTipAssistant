# 포켓 만화 2.0.5

중앙 표지 원본 232×280을 유지하고 배경 표지만 거리별로 경량화합니다. 중앙에 들어오는 표지는 116×140 중간 단계를 거쳐 원본으로 표시합니다. 머리 동작 없이 버튼으로 조작하며, 낮춘 밝기는 유지합니다.

공용 중계 주소 https://proxy.cors.dev 가 기본 설정되어 있습니다. PC 실행이나 가입 없이 휴대폰 통신사망에서 사용합니다. 기존 안경 Mirror v2는 그대로 사용합니다.

Source Studio 폴더: `PhoneSDK/examples/pocket-manga`. `integrations/webtoon-reader/README.md`에서 설치, 무료 서비스 제한, 버튼, 성능 비교와 검증 범위를 확인하세요. 활성 소스 동기화: `node integrations/webtoon-reader/sync-pocket.mjs`.
